# Problem Statement
The prescription experience between patient and doctor can be frustrating leaving both unsatisfied. The process can be streamlined to eliminate these issues. Patients face inaccessible prescription modification, and untailored prescriptions. Doctors face reliance on patient descriptions of symptoms.

# Core User Workflow & Value.
With our platform, patients can track down side effects or reactions associated with medication use, doctors can use this logging to quickly pinpoint what modifications they can make for the patient and create appointments instantaneously. The prescription experience can be streamlined to eliminate frustrations in the traditional appointment setting.

# Key Features

## Must-Have
- Roles
- Medication list
- Symptom logs
- Dashboard that highlights trends and flags adverse reaction.
- Prescription Appointment Request System
- Ticket queue based on severity
- Encrypted and secure communication

## Should-Have
- Priority-based secure doctor/patient messaging
- Instant appointment booking
- Offline symptom record keeping

## Could-Have
- Push notifications for patient for pill intake
- Biometric data integration
- A drop-menu menu of symptoms patients could log

## Won’t-have
- Open-response text boxes to data log 
- Appointment requests that get sent to doctors via email
